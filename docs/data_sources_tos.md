# データソース調査・利用規約まとめ

## 1. StatsBomb J1 2024 無料データ

### 概要
- **提供元**: Hudl StatsBomb × Wyscout
- **公開時期**: 2025年1月
- **対象**: J1リーグ 2024シーズン 全試合
- **データ内容**: イベントデータ（xG・パス・シュート・ドリブル等）＋Hudl身体的指標
- **形式**: JSON・CSV
- **取得先**: https://info.hudl.com/free-data-j1-league.html（フォーム登録後ダウンロード）
- **注意**: 標準の `statsbomb/open-data` GitHub リポジトリには含まれていない（別配布）

### 利用規約
| 項目 | 内容 |
|------|------|
| 利用目的 | 研究・分析・教育目的に限定（"research projects and genuine interest in football analytics"） |
| クレジット表記 | **必須** — "StatsBomb" をデータソースとして明記 ＋ 公式ロゴ使用 |
| 商用利用 | 明示的な禁止条項なしだが、研究・非商用が前提。商用目的は要問い合わせ |
| 再配布 | 条件付き（出典明記が必要） |
| 登録 | StatsBomb Resource Centre への登録を推奨（義務ではない） |

**→ 個人・研究・ポートフォリオ目的のダッシュボードなら利用可。クレジット表記を忘れずに。**

## 2. Jリーグ公式サイト (jleague.jp)

### 利用規約・著作権の要点
- コンテンツ（成績・スタッツ等）の著作権は **Jリーグ・データスタジアム等に帰属**
- 「営利・非営利を問わず複製不可（許諾なし）」と明記
- データの二次利用・商用利用は **事前申請・承認が必要**
- スクレイピングの明示的な禁止条項は見当たらないが、コンテンツの複製に該当するリスクあり

**→ スクレイピングは著作権的にグレー。個人利用・検証目的に留め、公開用途には使わない。**

---

## 3. J. League Data Site (data.j-league.or.jp)

### 概要
- **提供元**: Jリーグ公式（データスタジアム運営）
- **内容**: 試合結果・選手スタッツ・チーム成績（公式データ）
- **アクセス**: ブラウザからHTMLで閲覧可能、APIなし

### 利用規約
- Jリーグ公式と同系のため著作権ポリシーが適用される見込み
- 個別の利用規約ページは別途確認が必要

**→ スクレイピングはJリーグ公式と同様のリスクあり。**

## 4. 比較まとめ

| データソース | データの豊富さ | 最新性 | 利用可否 | 取得難易度 |
|-------------|--------------|--------|---------|-----------|
| StatsBomb J1 2024 | ◎ イベントデータ | △ 2024シーズンのみ | ○ 非商用・クレジット必須 | 低（ダウンロード） |
| Jリーグ公式スクレイピング | ○ 基本スタッツ | ◎ リアルタイム | △ グレー・個人利用限定 | 中 |
| api-football.com 無料 | ○ 基本スタッツ | × 2025以降非対応 | ○ | 低（API） |

## 5. 推奨方針

### Phase 1（現在）
**StatsBomb J1 2024 データを使う**
- フォームからダウンロード → `data/` に配置
- 2024シーズン全試合のイベントデータが使える
- IP制限なし、無料、取得が確実

### Phase 2（将来）
**現在シーズンのデータ補完**
- api-football.com 有料プラン（$10/月〜）で最新データを取得
- または Jリーグと正式なデータ利用契約を検討

### やらないこと
- Jリーグ公式サイトの大規模スクレイピング（著作権リスク）
- ダッシュボードで出典を明記せずにデータを使うこと
